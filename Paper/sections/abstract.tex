\begin{abstract}
    We present a novel parallel wait-free breadth-first search (BFS) algorithm that significantly improves performance by minimizing synchronization overhead and ensuring progress across all threads. The algorithm leverages a custom dynamic array (CDA) to store vertices at each depth level, supporting multiple reader single writer (MRSW) operations and reducing memory contention. Vertices at the same depth are processed in parallel, and a helping mechanism balances the workload among threads.
    
    We evaluate the proposed BFS algorithm on synthetic and real-world graphs across a range of graph sizes, densities, and thread counts. Experimental results demonstrate performance improvements over sequential BFS and an existing parallel BFS algorithm. Our work highlights the effectiveness of wait-free techniques in parallel breadth-first traversal.
\end{abstract}
