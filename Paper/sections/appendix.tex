\section{Atomic CAS-Based Parallel Labeling}
\label{sec:atomic_cc}

In this algorithm, the $comps$ array is an array of atomic integers, initialized to $-1$, and $comp$ is an atomic integer, initialized to $0$. We use the atomic compare-and-swap (CAS) operation to assign the component identifier to each vertex. Each thread is statically assigned a set of vertices and looks for an unassigned vertex, attempting to assign it a component ID using CAS. The atomic fetch-and-add operation increments the $comp$ variable, providing the ID to be assigned to the component. If a thread fails to update the vertex, it indicates that another thread has already assigned a component ID, and the thread moves on to the next unassigned vertex. If the thread succeeds, it enqueues the vertex into a queue and initiates a BFS from that vertex.

Since multiple threads may simultaneously attempt to assign component IDs to the same vertex, we use CAS operations to ensure that each vertex is assigned a unique component ID exactly once. For every vertex $u$ dequeued from the queue, the thread attempts to assign the component ID to all its neighbors using CAS in a loop. For a neighbor $v$ of $u$, if the CAS operation succeeds, the thread enqueues $v$ into the queue and continues its operation. If the CAS operation fails, the thread checks whether the component ID of $v$ is less than the current component ID being assigned. If it is, the thread stops processing this component and moves on to the next unassigned vertex. If the component ID of $v$ is greater than the current component ID, the thread retries the CAS operation. If the component ID of $v$ equals the current component ID, the thread proceeds to the next neighbor of $u$.

\subsubsection{Proof of Correctness}

Since there are a finite number of threads, the component ID will be assigned by the thread with the lowest component ID. This guarantees that all vertices in the same connected component are assigned the same component ID, which corresponds to the lowest component ID among all threads that processed the component.

Furthermore, since each component ID is used only once, the assigned component IDs remain unique.

These properties ensure that the algorithm correctly assigns component IDs to all vertices.
