\section{Times per Thread Count}
\label{sec:app-times}

Tables~\ref{tab:app-lj} to~\ref{tab:app-kron} list the median times per search that Figure~\ref{fig:scaling} plots, for every graph, program, thread count and placement; Section~\ref{sec:exp-setup} describes how we measured them.

\pgfplotstableset{
    times/.style={
        string type,
        column type=r,
        columns={t, wd, mem, gapbs, gbbs, pasgal},
        columns/t/.style={column name=$T$},
        columns/wd/.style={column name=\wfdo},
        columns/mem/.style={column name=\wfdomem},
        columns/gapbs/.style={column name=GAPBS},
        columns/gbbs/.style={column name=GBBS},
        columns/pasgal/.style={column name=PASGAL},
        begin table={\begin{tabular}[t]},
        every head row/.style={before row=\toprule, after row=\midrule},
        every last row/.style={after row=\bottomrule},
    },
}

% one table per graph, with the two placements side by side; the braces keep the
% outer tabular from taking the ampersands that pgfplotstable reads as its own
\newcommand{\timestable}[2]{%
    \footnotesize
    \setlength{\tabcolsep}{4pt}
    \begin{tabular}{@{}c@{\hspace{2.5em}}c@{}}
        One socket & Two sockets \\[0.3ex]
        {\pgfplotstabletypeset[times]{#1}} & {\pgfplotstabletypeset[times]{#2}} \\
    \end{tabular}%
}
